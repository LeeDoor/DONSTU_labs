Вариант 10: Работа с числами Фибоначчи

Реализовано:
1. Шаблон функции generateFibonacci<T>(int n) для генерации n чисел Фибоначчи
   - Работает с любыми числовыми типами (int, long, double, и т.д.)
   
2. Шаблонный класс FibonacciSequence<T> для хранения последовательности Фибоначчи
   - Содержит метод print() для вывода последовательности
   - Содержит методы getSequence(), size() для доступа к данным
   
3. Специализация функции для типа short
   - Добавлена проверка на переполнение
   - Выводит предупреждение при обнаружении переполнения
   
4. Специализация класса для типа int
   - Добавлены методы getAverage() и getSum() для вычисления среднего значения и суммы
   - Добавлен метод printStatistics() для вывода статистики
   - Переопределен метод print() для специализированного вывода

Файлы проекта:
- fibonacci.hpp - содержит все шаблоны и специализации
- main.cpp - демонстрационная программа
- Makefile - для сборки проекта
- create_template_files.sh - скрипт создания файлов

Инструкция по сборке и запуску:
1. make       - компиляция программы
2. make run   - запуск программы
3. make clean - удаление скомпилированных файлов
4. make test  - компиляция и запуск
