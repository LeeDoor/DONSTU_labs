# Лабораторная работа №4: классы в Java

Реализованы задания 1–9 из `lab4.pdf`:

- классы автомобилей, двигателей, типы машин, проверка регистрационных знаков и автобаза с состояниями;
- неизменяемые комплексные числа и статические элементарные функции;
- объектная модель графика с текстовым выводом и UML-диаграммой в `class-diagram.puml`.

Для специальных машин принят отдельный формат номера `SP-0001` (4–6 цифр).
Обычные номера проверяются в формате `А 123 ВС 61 RUS` или
`А 123 ВС 161 RUS` с разрешенными ГОСТ буквами.

Запуск всех демонстраций: `./run.sh`. Отдельное задание: `./run.sh 7`.
Запуск проверок: `./test.sh`.
