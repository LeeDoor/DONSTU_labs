# Лабораторная работа 8

Программа читает формальную грамматику, определяет, является ли она регулярной, строит по регулярной грамматике НКА и преобразует его в ДКА.

## Формат ввода

- терминалы через запятую, например `a,b`;
- нетерминалы через запятую, например `S,A`;
- правила по одному на строке, сначала левая часть, затем пробел и правая часть;
- пустая строка завершает список правил и обозначает ε в правой части;
- начальный символ отдельной строкой.

Пример:

```text
a,b
S,A
S aA
S b
A aS
A

S
```

Построение автомата выполняется по алгоритму из конспекта для правил `A -> aB`, `A -> a` и `S -> ε`: при необходимости добавляется новый конечный нетерминал `N'`, затем правила преобразуются в переходы. Леволинейные грамматики распознаются как регулярные, но этот алгоритм построения к ним неприменим. Если грамматика подходит для построения, рядом с программой создаются `grammar_nfa.png` и `grammar_dfa.png` (нужен Graphviz `dot`).

Запуск: `./run.sh` (компилятор g++ и Graphviz должны быть установлены).
